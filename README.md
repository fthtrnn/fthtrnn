## ⭐ Featured project

### [OpenHRM](https://github.com/fthtrnn/openhrm) — open-source HR management platform

Self-hosted HRM covering the whole employee lifecycle in a single panel:
recruitment & candidate portal · personnel records · leave & advance approvals ·
in-app e-signatures · asset tracking · payslip distribution · KVKK / GDPR tooling ·
RBAC + 2FA · AES-256 encrypted personal data.

🌍 **Trilingual UI — Turkish · German · English**, switchable per user.

`Next.js 16` · `React 19` · `TypeScript` · `Prisma` · `PostgreSQL` · `Tailwind CSS` · `Docker`

> 🇹🇷 **OpenHRM**, işe alımdan işten çıkışa tüm personel sürecini tek panelde toplayan,
> kendi sunucunuzda çalışan açık kaynak bir İK platformudur: aday portalı, özlük, izin/avans
> onayları, sistem içi e-imza, zimmet, bordro dağıtımı ve KVKK araçları.
> Arayüz **Türkçe, Almanca ve İngilizce** kullanılabilir. →
> [Türkçe kurulum rehberi](https://github.com/fthtrnn/openhrm/blob/main/README.tr.md)

```bash
git clone https://github.com/fthtrnn/openhrm.git && cd openhrm
node scripts/setup-env.mjs && docker compose up -d --build   # → http://localhost:8940
```
